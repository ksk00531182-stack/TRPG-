# TRPG Session Room

ブラウザだけで使えるTRPGセッション管理ページです。

## 起動

ローカルではプロジェクトルートで `npm start` を実行し、`/trpg-session-room/index.html?mode=gm` を開いてください。

## 機能

- シーンメモの編集と自動保存
- イニシアチブ順の確認と追加
- ダイスロール（個数・面数・修正値）
- セッションログの追加とクリア
- 参加者の追加
- 調査資料の複数登録とサムネイル表示
- セッション中に見せる演出画像の登録と拡大表示
- 調査資料・演出画像へのPDF追加とブラウザ内参照
- 状態のリセット

セッションデータはGMのブラウザに保存され、Socket.IOで同じルームのPC画面へ同期されます。GMの「参加URL」から共有したURLにはルームIDが含まれます。サーバー再起動時も保持するには、別途データベース保存が必要です。

## GM画面とPC画面

- GM画面: `index.html?mode=gm`
- PC画面: `index.html?mode=pc`

GM画面の「参加URL」ボタンで、PC向けURLをコピーできます。PC画面ではシーンメモ、画像追加、参加者追加、ログ編集、リセットなどのGM操作が非表示になり、セッション情報を閲覧する専用画面になります。

GM画面で背景画像を設定したあと、調査資料・演出画像の各カードにある「背景に配置」を押すと画像を背景へ重ねられます。配置した画像はGM画面上でドラッグして位置を調整でき、PC画面にも同じ位置で表示されます。キャラクター画像は「⊕」ボタンから背景へ配置できます。

GM画面もPC画面と同じ全画面ステージで表示されます。画面上部のGM専用タブからキャラクター、資料、演出画像、背景を追加できます。画像を追加すると自動で背景へ配置されるため、そのままドラッグして位置を調整できます。右端の「素材一覧」から従来の資料一覧も開けます。

背景上の画像をクリックすると操作パネルが表示されます。サイズスライダー、左右回転、表示・非表示、削除を操作でき、変更内容は保存されてPC画面にも反映されます。

追加画像はレイヤーとして管理されます。キャラクター追加は「キャラクター層」、資料・演出画像追加は「資料・演出層」に入り、操作パネルから分類変更、前面・背面への移動ができます。

GM画面右下のレイヤー一覧では画像が1行ずつ表示され、上の行ほど前面です。行をドラッグ＆ドロップして並べ替えると重なり順を変更できます。各行から対象画像を選択し、前後移動・表示切替・削除を直接操作することもできます。

サイズ変更はタブではなく、「キャラクター」「資料」「アイコン」「背景」の4つの独立した枠で表示されます。各枠で対象画像を選び、専用スライダーでサイズを変更できます。背景枠では背景画像の拡大率を変更します。各レイヤー行のプレビューは名前の左側に常時表示されます。

各枠にはカテゴリ専用のレイヤー一覧も表示されます。行をクリックすると、そのカテゴリの画像を選択してサイズ変更や表示切替などを行えます。独立枠内には大きなプレビュー画面を置かず、一覧の小さなプレビューで確認します。

画像の選択はプルダウンを使わず、各カテゴリ枠のレイヤー行をクリックして行います。

右下の統合レイヤー一覧は廃止し、キャラクター・資料・アイコンの各枠に操作付きレイヤー一覧を配置しています。各枠の行から表示切替・削除ができ、同じ枠の中でドラッグ＆ドロップによる並べ替えもできます。

Renderなどへデプロイする場合は、Web ServiceのStart Commandに `npm start` を設定します。GMとPCは同じサーバーURLの参加URLを使ってください。

## 画像フォルダ

- `assets/backgrounds`: セッション背景
- `assets/characters`: 登場人物画像
- `assets/clues`: 調査資料・証拠画像
- `assets/scene-images`: セッション中に見せる演出画像

画面上の追加ボタンから画像を選ぶと、すぐにサムネイルへ反映されます。サムネイルをクリックすると拡大表示できます。
調査資料と演出画像はPDFにも対応しています。PDFはカードからブラウザ内で開けます。PDF自体を背景へ配置することはできませんが、内容を参照する資料として利用できます。
